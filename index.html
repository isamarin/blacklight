Built for players Microsoft left on the desktop

xCloud + home streaming, gamepad and keyboard, friends online, library and profile — in a native Tauri shell.

xCloud & console

Stream cloud titles and your Xbox One / Series over the network from one app.

macOS & Windows

Native desktop builds (Tauri 2 + SvelteKit). Public beta downloads on GitHub Releases.

Controls that fit

Gamepad support, keyboard map, rumble on xCloud — Steam Deck friendly with a mapped Nexus key.

Friends & library

Online friends sidebar, continue-playing hero, recent and new games, profile with gamerscore.

Region-aware streaming

Smarter GSSV region handling and force-IP presets when your stream host and UI region disagree.

Open source beta

CalVer releases, public repo, stream debug stats. Not affiliated with Microsoft or Xbox.
